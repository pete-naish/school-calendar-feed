St Paul's C of E Primary (Enfield) — Calendar Feeds

These feeds mirror the school's public Upcoming Events page, split into separate subscribable calendars so you can pick only what's relevant to your family. Each one refreshes automatically every few hours — subscribe once and new events appear without you doing anything.

Apple/Outlook: tap "Subscribe" below (or use the webcal:// link with File → New Calendar Subscription on Mac).
Google Calendar: copy the "ics" link, then go to Other calendars → + → From URL and paste it.

Preview & use as a calendar

Toggle on whichever calendars are relevant to you to see what you'd actually get. This works as a calendar in its own right too, if you'd rather not subscribe anywhere - your choices are remembered on this device.
