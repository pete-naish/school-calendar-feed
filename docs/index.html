St Paul's C of E Primary (Enfield) — Upcoming Events Calendar

This feed mirrors the school's public Upcoming Events page as a subscribable calendar. It refreshes automatically every few hours — subscribe once and new events appear without you doing anything.

Subscribe (Apple/Outlook) calendar.ics (raw file)

Google Calendar

  1. Open Google Calendar → Other calendars → + → From URL
  2. Paste: https://pete-naish.github.io/school-calendar-feed/calendar.ics

Apple Calendar (iPhone/iPad/Mac)

  1. Tap the "Subscribe" button above, or go to File → New Calendar Subscription on Mac
  2. If prompted for a URL instead: webcal://pete-naish.github.io/school-calendar-feed/calendar.ics

Outlook

  1. Add calendar → Subscribe from web
  2. Paste: https://pete-naish.github.io/school-calendar-feed/calendar.ics
